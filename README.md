# rudvan-content-source

This repository stores raw educational source assets and is not used directly for training.

Here we collect books, notes, worksheets, previous year questions (PYQs), NCERT, exemplar, and reference content.

Extract Knowledge → Generate Knowledge Packages → Generate Datasets
